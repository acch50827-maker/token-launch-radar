How the value is scored

Every protocol below records no token, so there is no market price to read. The radar scores each one from the snapshot's own figures only:

implied value = TVL × 0.30 × growth × age × launch likelihood

  • TVL × 0.30 — a token's implied value is taken as roughly a third of the value the protocol already secures.
  • Growth — 1 plus the 7-day TVL change, clamped between 0.5 and 2.5. Fast-growing TVL is worth more than shrinking TVL.
  • Age — 1 plus 3% per year tracked, capped at 4 years. A record that has survived a while counts for more.
  • Launch likelihood — 0.05 for a centralised exchange, a bridge, or a wrapped/staked product of a token that already trades; 0.3 for a versioned build (V2, 2.0); 1 for everything else. Those are not launches waiting to happen.

Implied value is this radar's own claim, never a prediction that a token will be issued, or when. Farm steps are generic plans: check the protocol's own docs before moving money.
